# 作业列表

双击桌面“作业列表”启动。首次启动立即刷新，以后每隔一小时刷新网络学堂服务器给出的当前学期所有课程，只显示“未提交”作业，按截止时间升序排列。过期未交作业在最前，未知时间在末尾。时间按北京时间显示，剩余时间在本地持续更新。

窗口最小化后继续运行，右上角关闭按钮也会最小化；底部“退出程序”才会停止运行。电脑关机或休眠期间无法刷新，恢复后会补做一次到期刷新。不修改系统电源设置，不自动注册开机启动。

列表显示所属课程、作业名称、主要内容摘要、截止时间和剩余时间。选中一项后，下方显示完整作业正文及附件名称，可滚动阅读。摘要直接取自教师发布的说明；只有附件的作业显示附件名称，可通过“打开选中作业”或双击到原网页查看具体题目，不自动下载附件。

小组内其他成员已提交、个人无需再提交的作业，可以选中后点击**列表上方红色的“删除选中作业（Delete）”**，也可以在列表中按键盘 Delete 键。该按钮仅在本地隐藏这一门课程的这一项作业，不修改学校网站上的作业或提交状态。删除记录保存在 `data/hidden.json`，重启和每小时刷新后依然生效。点击旁边的“已删除”可查看所属课程和作业名称，选中后点击“恢复选中作业”；支持多选恢复。恢复后仅当前学期仍未提交的作业重新显示。顶部计数只统计未被隐藏的待处理作业。

点击“立即刷新”可手动更新。程序只读网络学堂，不提交、修改作业。单个课程读取失败时，该课程旧数据标为“旧数据”；正文读取失败时保留旧正文并明确标注。登录失效时保留上次结果并显示提示，不能将读取失败理解为没有作业。隐藏作业仍参与服务器列表核对，但不额外请求其正文。

Cookie 复用原 MCP 项目的 `config/local.json`，不写入界面日志或缓存。登录过期后，在浏览器登录，再点击“更新 Cookie”粘贴新的请求头值，程序会更新原配置并立即刷新。此更新也会对 MCP 服务下一次启动生效。课程、作业和运行状态缓存在本程序目录的 `data` 文件夹中，包含个人课程信息，请勿公开。

## 安装与依赖

依赖 Python 3.11（含 Tkinter）、Node.js 22.18 或更新版本，以及已安装依赖并编译的 `thu-learn-mcp-server` 项目。界面只使用 Python 标准库；读取逻辑复用项目的 Cookie、限速和重试处理。请求间隔至少一秒，读取失败自动重试两次。单轮读取最多等待五分钟，后续整点间隔仍会重试。

在项目根目录构建后运行：

```powershell
npm ci
npm run build
if (!(Test-Path -LiteralPath "config/local.json")) {
    Copy-Item -LiteralPath "config/example.json" -Destination "config/local.json"
}
notepad "config/local.json"
```

在打开的配置文件中填写有效的网络学堂 Cookie，保存后，在原项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File desktop-app/install.ps1 -Launch
```

首次下载、Cookie 获取、完整配置及路径参数见 [仓库主 README](https://github.com/123huangcan250/netschool-undone_homework#readme)。更新时先退出程序，在原项目执行 `git pull --ff-only`、`npm ci`、`npm run build`，再重新执行安装脚本。仅更新 Git 仓库不会更新桌面的程序副本；重跑安装脚本会保留 `data` 中的个人缓存与删除记录。

安装脚本创建桌面快捷方式 `作业列表.lnk` 和 `作业列表程序` 文件夹，`app-settings.json` 引用原项目路径和本地 Cookie 配置。请保留原项目及其依赖，不要移动或删除；如果移动项目，请修改设置中的路径。不复制 Cookie 到桌面设置文件。

开发验证：

```powershell
npm run check
python desktop-app/test_homework_app.py
```
