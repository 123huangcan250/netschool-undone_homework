# 只读评估集

`offline.xml` 包含 10 个固定、可用精确答案校验的问题，**仅对应 `test/helpers.ts` 中的合成课程数据**，不对应真实用户课程。合成数据可通过官方 SDK 调用的 `get_course_list`、`get_homework_list`、`get_homework_detail` 读取；不需要或允许在评估中调用提交工具。

这些问题用于后续衡量客户端模型如何组合课程、作业、详情工具，不将其包装为真实学期评估。预期答案在 `test/evaluation.test.ts` 中通过实际 MCP 只读调用验证。尚未运行外部模型评分或需要 API 密钥的评估 harness。

真实账号评估需要用户先完成只读联调，再以已经结束、内容固定的历史学期生成独立问题与可复核答案。当前没有有效 Cookie，无法诚实生成真实账号标准答案。
